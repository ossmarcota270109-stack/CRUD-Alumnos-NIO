# Sistema de Control de Alumnos (CRUD con Java NIO)

Aplicación de consola en Java que implementa las operaciones fundamentales de un CRUD sobre un archivo plano (`alumnos.txt`), utilizando el paquete no bloqueante `java.nio.file.Path` y `java.nio.file.Files`.

## Instrucciones de Ejecución
1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto en NetBeans.
3. Ejecutar la clase principal `CRUDAlumnosNIO.java` presionando `Shift + F6`.
